# Two-minute demo recording script

## Gate before recording

This is a recording plan, not an existing video or proof of live payment. Do not narrate pending activity as successful. The public website, genuine Testnet flow and public recording URL remain unverified.

Use the actual approved public URL when available. Confirm it works signed out. Keep the same browser session and tunnel hostname throughout: grants are immutable, and changing a temporary URL loses that browser session's access. Do not reset records or create a new owner to repeat a purchase.

Prepare before the timed section: a saved default goal (no familiar skills, all formats, 30 budget / 10 reserve / 10 cap); owner ownership verification; a genuine verified Velo service payment; approved provider rules; confirmed Noir device, policy and 20-XLM escrow funding. Review their actual transaction references. No real-money network or Mainnet prompt is acceptable.

**Start screen recording before the first real Start agent click.** Capture the actual first authorization/claim sequence so it can be edited honestly; an already consumed grant cannot be reset for a better take. If confirmation takes longer than the script window, record the wait and trim it with a visible "Network wait trimmed" note. Do not manufacture a success state or imply a latency benchmark. If a transaction outcome is uncertain, show pending/reconciliation and finish the real flow before making a success video.

Keep .env files, wallet secret/recovery screens, DevTools, session tokens, signed transactions, private records and sample access-code text off screen. Wallet approvals are performed by the owner; record the app after the prompt closes. Do not expand access-code content for a public recording.

## Exact no-paid-tool recording/export steps

1. Use an already installed screen recorder. If available, open Windows Snipping Tool, choose Record, select only the browser's app area and start. Do not install a paid recorder or begin a trial. If that version has no Record option, use an existing local recorder or Xbox Game Bar for the browser (Win+G, Capture, Start recording) yourself.
2. Record the full genuine flow and private wallet actions outside the selected area. Keep the same window/session and wait for confirmation. Save the original privately under artifacts, which is ignored by Git.
3. Trim to two minutes with an existing local editor, keeping the order of events. Label omitted network waits. Never splice a simulated order into an actual payment sequence. Export MP4, preferably 1080p, with readable amounts and browser controls that reveal no secrets.
4. Review the entire exported video for credential/payload/code leaks and for truthful payment states before upload.
5. Upload using an existing no-charge account (for example an unlisted YouTube video or a view-only Drive file). If an upgrade, card or charge is required, stop. User uploads and publishing require a final sharing decision; none is done by this script.
6. Open the view URL in a signed-out/private browser window. Verify playback without login or an access request. Only then replace README's Pending demo link and mark the checklist item complete.

No recording or upload is claimed by the existence of this file.
